# DESIGN.md — дизайн-система лендинга Террикон Тех

Файл для агентов и людей: как этот продукт должен выглядеть. Читать перед
любой правкой UI. Кодовые правила — в [CLAUDE.md](CLAUDE.md).

## Контекст продукта

Одностраничный лендинг студии разработки «Террикон» (Донецк; ядро —
два основателя, команда ~20 человек). Аудитория — заказчики сайтов/приложений/платформ из РФ.
Единственная задача страницы — довести до клика «Написать в Telegram».
Тон: уверенный, без корпоративной воды, «простые парни, одержимые
созданием ярких проектов».

## Токены

### Цвет
| Токен | Значение | Роль |
|---|---|---|
| ground | `#0C0C0C` | фон всего сайта (тёмный всегда) |
| paper | `#FFFFFF` | фон секции «Услуги» (единственная светлая) |
| ink | `#D7E2EA` | основной текст на тёмном |
| ink-soft | `#BBCCD7` | лого, контурная графика, вторичные элементы |
| accent | `#FF6A00` | сигнальный оранжевый — см. правило ниже |
| ink-dark | `#14161A` | заголовок hero на светлом видео (светлая тема, lg) |

Прозрачности текста: не ниже `/60` на #0C0C0C (WCAG AA); подписи `/65`.

**Правило акцента**: #FF6A00 — «сигнальный огонёк на мачте террикона».
Тратится точечно: CTA футера, тумблер, ::selection, фокус-обводки,
nav-ховер, каталожные индексы услуг, огоньки в графике. Никогда —
заливкой больших плоскостей и не в двух соседних элементах сразу.

### Типографика
| Роль | Шрифт | Использование |
|---|---|---|
| display | Unbounded 600/700/900 | заголовки секций, цифры, водяной знак |
| body | Golos Text 400/500/600 | всё остальное; у Golos нет 300 — font-light запрещён |

Заголовок hero: 11.2vw (слово «Террикон Тех» = ~96% ширины). Водяной
знак футера: `min(15.8vw, 280px)` («Террикон» в Unbounded-900 = 6.19em
на единицу кегля; мерить только Range API по глифам). Капс — только
мелкие лейблы с letter-spacing; заголовки в смешанном регистре.

### Графический язык
Контурные силуэты `#BBCCD7` opacity 0.3, штриховка opacity 0.12,
сигнальный огонёк-точка #FF6A00. Носители: TerrikonRidge (гребень
терриконов перед футером), глифы «О нас» (AboutGlyphs), водяной знак.
Новую декоративную графику рисовать в этом языке, не тащить чужие
иконпаки.

## Мошн

- Весь framer-motion обёрнут в `MotionConfig reducedMotion="user"`;
  JS-анимации (параллакс марки) гейтятся `prefers-reduced-motion`, а
  hero-атласы — ещё и системным `Save-Data`.
- Скролл к якорям — smooth (с reduced-motion guard в index.css).
- Главный мошн-момент — скраб hero (кадр меняется от положения мыши) с
  тающей подсказкой; остальное — сдержанные FadeIn при скролле.
  Не добавлять новые «эффекты ради эффектов» — боллдность уже
  потрачена на hero.

## Ключевые механики (не ломать)

- **Источники hero**: all-intra MP4 и маски лежат в
  `assets/hero-source/` только как вход для `scripts/bake_subject_atlas.py`.
  Runtime не делает video seek и не создаёт WebGL-контекст.
- **Фигура поверх заголовка**: SubjectKeyCanvas синхронно рисует два WebP-
  атласа по 40 кадров (8×5, тайл 960×540): полный кадр `scene-*` под
  заголовком (z-0) и прозрачную фигуру `subject-*` над ним (z-2), текст —
  между ними (z-1). Так сохраняются фон/свечение версии Савелия и перекрытие
  букв без декодирования MP4 при каждом движении мыши. При замене источника
  обязательно пересобрать обе пары атласов и постеров.
- Кроп кадров: мобильный — object-position по теме (лама центр, манекен
  68%); lg — right-top; тёмная на окнах шире 16:9 — contain по высоте
  с центровкой и растворением боковых полей.

## Компонентные паттерны

- CTA: ContactButton — прямая ссылка на Telegram (`TELEGRAM_URL`),
  вариант glass (тёмный/видео фон) и dark (белая секция); CTA стоит в
  hero, «О нас», после «Услуг», после «Проектов» и в футере.
- Списки типа «Услуги»: каталожный индекс (капс-лейбл в accent,
  tabular-nums) над названием в display; НЕ гигантские цифры — номера
  не последовательность.
- Секции с тёмным фоном разделяются скруглёнными «карточными» стыками
  (rounded-t-[40-60px]) — это архитектура страницы, сохранять.
