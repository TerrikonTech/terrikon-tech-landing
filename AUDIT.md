## 🔴 Критично — до показа любому клиенту

### 1. «Проекты» и марки — чужие работы с motionsites.ai, подписанные «Клиент»
`src/components/MarqueeSection.tsx:3-25`, `src/components/ProjectsSection.tsx:15-21`
- Все 21 GIF марок и 5 «кейсов» («Space Voyage», «CodeNest», «Vex Ventures», «Stellar AI», «ASME») — прямые хотлинки на витрину шаблонов motionsites.ai. Названия взяты из их же URL. Три карточки подписаны категорией **«Клиент»** — фабрикация кейсов; ASME вдобавок реальный узнаваемый бренд.
- Вес: замерено 8.4–14.4 МБ на GIF → **~100–250 МБ** на полную прокрутку. На мобильном интернете страница неподъёмна; 63 img-ноды с GIF-декодом могут крашить вкладку на слабом железе.
- URL захешированы чужой сборкой (`-Cgppc2qV.gif`) — при любом редеплое motionsites.ai вся витрина молча превращается в битые картинки.
- **Фикс:** свои кейсы (GasTracker, транспорт-PWA, СКАЙНЕТ-стенд, meat…) — скринкасты → muted-loop mp4/webm по 200–500 КБ в `public/`; категорию «Клиент/Личный» → тип работы + 1–2 строки результата. Пока превью нет — честнее скрыть секцию.

### 2. Конверсионный путь порван: ни одна кнопка не ведёт в Telegram — **фикс в PR #30 (draft)**
`src/components/ContactButton.tsx:17-21`, `src/components/Footer.tsx:64-80`
- Обе кнопки «Связаться» только скроллят к футеру, где контакт — текстовая ссылка «Телеграм» 14px в четвёртой колонке. Два клика + поиск ссылки = слив конверсии.
- После «Услуг», «Проектов» и «Команды» CTA нет вообще — пик намерения остаётся без кнопки.
- **Фикс:** «Связаться» → прямой `<a href="https://t.me/…" target="_blank">`; CTA-блоки после услуг и проектов; в футере крупный «Обсудить проект в Telegram» + «отвечаем в течение дня».

### 3. Раздвоение: «Хай, я Джек» vs «Мы — Террикон»
`HeroSection.tsx:146,157`, `index.html:6`, `AboutSection.tsx:8-9`, `TeamSection.tsx`
- Hero продаёт персону «Джек, 3D-художник» (ед. число), следующая секция — «Мы — Террикон, студия», в команде Джека нет. Title вкладки — «Джек — 3D-художник». Выглядит как шаблон с незаменённым именем.
- **Фикс (вариант а, сохраняет характер):** Джек = цифровой талисман студии — подпись в hero, карточка-маскот в «Команде»; тогда манекен/лама обретают смысл. Либо (б) убрать Джека. В обоих случаях `<title>` → «Террикон — студия разработки: сайты, приложения, 3D».

### 4. Шаринг и индексация: карточки в TG нет, для ботов страница пустая — **меты+og.jpg в PR #30 (draft); пререндер/noscript остаются**
`index.html:3-15`
- Нет `meta description`, `og:*`, `twitter:card` — а канал продаж это пересылка ссылки в Telegram. Боты мессенджеров JS не исполняют, но статические теги в `index.html` сработают — их просто нет. og-image 1200×630 тоже нет.
- SPA: в статическом HTML пустой `<div id="root">` — Яндекс (основной поисковик аудитории) рендерит JS выборочно; сниппет пустой.
- **Фикс:** статический блок мет в `index.html` + og-картинка в `public/`; `<noscript>` с текстом и контактом; в идеале пререндер (`vite-ssg` — одностраничник, тривиально).

## 🟡 Средний приоритет

13. **Контраст (WCAG AA, замеры на #0C0C0C):** `Footer.tsx:86` копирайт `/40` = 3.17:1 — фейл; `Footer.tsx:40` и `TeamSection.tsx:102` `/50` = 4.32:1 — фейл. Поднять /40→/60, /50→/65 (визуально почти неотличимо).
14. **CTA-кнопка: `outline-none` без focus-visible** (`ContactButton.tsx:22`) + **нет accessible name** (текст собран из aria-hidden посимвольных span — скринридер объявляет пустую кнопку; подтверждено в дереве доступности). Дать `aria-label="Связаться"` и `focus-visible:outline`. Семантически это `<a href="#contact">`.
15. **Прелоадер:** минимум 1.6 с всегда + ждёт `window.load` (включая тяжёлые видео) без верхней границы — на медленной сети тетрис на десятки секунд. `Promise.race` с потолком ~3.5 с, минимум → 0.8–1 с. Плюс SR-разметка: `role="status"`, грид `aria-hidden`.
16. **ScrubVideo без обработки `error`** (`HeroSection.tsx:41-65`): флаг `seeking` залипает навсегда, если видео упало — скраб мёртв до перезагрузки. Слушать `error` + сброс. И подсказка «двигайте мышью» — фича сейчас необнаружима.
17. **Tetris: side-эффекты внутри setState-апдейтеров** (`TetrisLoading.tsx:219-249,296-302`) — в StrictMode двойной вызов планирует двойную очистку строк по устаревшим индексам → глюк сетки. Вынести эффекты из апдейтеров.
18. **Ландмарки:** всё, включая `<nav>` и `<footer>`, живёт внутри корневого `<main>` (`App.tsx:21-33`). Корень → div, навбар → header, footer наружу.
19. **Тумблер темы обещает тему, а меняет видео** — весь сайт всегда тёмный, «Услуги» всегда белые (`ThemeSwitch.tsx`, aria «Переключить тёмную тему»). Либо честные иконки/лейбл «сменить сцену», либо настоящая тема.
20. **Тексты:** «О нас» — универсальная вода («создадим что-то невероятное») — заменить на отличие: «без менеджеров-прослоек, двое инженеров, полный стек»; «Команда» — фраза рассыпается синтаксически («двое разработчиков…, чтобы») и продаёт «свои проекты» вместо клиентских; роли обоих одинаковые — развести (фронт/3D/моушн vs бэк/инфра/интеграции).
21. **SEO-гигиена:** нет robots.txt, sitemap.xml, canonical (дубли при utm-метках), JSON-LD Organization; favicon только SVG (Safari<17 и мессенджеры не понимают) — добавить png 32×32 + apple-touch-icon 180×180; нет `theme-color` (#0C0C0C).
