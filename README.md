# Джек — 3D-художник (лендинг-портфолио Террикон)

Одностраничный лендинг-портфолио на русском. Тёмная тема (#0C0C0C), шрифт Montserrat (кириллица), тяжёлая скролл-анимация, две темы оформления.

**Стек:** Vite · React 18 · TypeScript · Tailwind CSS 3.4 · Framer Motion 12 · Lucide React

## Секции
1. **Прелоадер** — падающий тетрис (белые фигуры на чёрном), висит до загрузки страницы.
2. **Hero** — навбар (лого-знак + О нас / Проекты / Контакт + тумблер темы ☀/🌙), заголовок «Хай, я Джек», скраб-видео на весь экран: кадр мотается **движением мыши** (на таче — автоплей). Светлая тема — глянцевый манекен, тёмная — лама в VR-очках. Стеклянная кнопка «Связаться» (liquid glass) скроллит в подвал.
3. **Marquee** — две встречные ленты из 21 GIF-превью, движутся от скролла страницы.
4. **О нас** — 4 декоративные 3D-иконки, посимвольное проявление текста при скролле (opacity 0.2 → 1).
5. **Услуги** — белая секция: лендинги под ключ, фулстек, приложения, платформы, ПО.
6. **Проекты** — 5 sticky-карточек с одним GIF в каждой: липнут к верху и уменьшаются, пока следующая наезжает поверх.
7. **Команда** — Олег Зотов и Савелий Спорышев (фото в `public/team/`).
8. **Футер** — Террикон: колонки ссылок, контакт только Телеграм, контурный водяной знак «ТЕРРИКОН».

## Запуск
```bash
npm install
npm run dev     # dev-сервер Vite на http://localhost:5175
npm run build   # прод-сборка (tsc + vite build) в dist/
```

## Как устроено (ключевое)
- **Скраб-видео**: локальные перекодировки в `public/` (1080p, H.264 **all-intra** — сик по любому времени декодирует один кадр, ~2–4 мс). mousemove копит целевое время, сики — раз в кадр через rAF после `seeked`.
- **Тема**: состояние в `App`, сохраняется в `localStorage` (`jack-theme`); светлая тема на lg затемняет текст hero (фон видео светлый).
- **Лого**: `LogoMark` — CSS `mask-image` по альфа-маске `public/logo-mark.png`, цвет фоном (2 варианта: `#BBCCD7` и чёрный); favicon.svg переключает цвет по `prefers-color-scheme`.
- Остальные картинки — внешние URL (figma.site, motionsites.ai), локальных сборочных ассетов минимум.
