# TerrikonTech — шаблон проекта

Стартовый шаблон для новых репозиториев организации. Уже содержит:

- `CLAUDE.md` + `AGENTS.md` — правила агентов и протокол задач (ветки/PR/issues/доска).
- `.github/` — шаблоны issue и pull request.
- `.gitignore` — базовый (режет секреты, БД, `node_modules`, `.venv`).

## Как создать новый проект
Нажми **«Use this template» → Create a new repository**, выбери владельца `TerrikonTech`, приватность — private.

После создания допиши в `CLAUDE.md`/`AGENTS.md` раздел «Что это / Запуск» под конкретный проект (остальное — общий протокол, менять не нужно).
