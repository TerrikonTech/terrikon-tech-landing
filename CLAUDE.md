# CLAUDE.md — базовый свод правил TerrikonTech

> Читают Claude Code (`CLAUDE.md`) и Codex (`AGENTS.md`) — содержимое обоих файлов **должно совпадать**. Это org-baseline: копируй в новый проект и допиши раздел «Что это / Запуск» под конкретный репозиторий.

## 🟢 Протокол работы с задачами
Перед началом **любой** работы:
1. `gh issue list --state open` — что открыто и на кого назначено.
2. `gh pr list --state open` — какие ветки в работе и какие файлы трогают. **Пересекаешься по файлам с чужим PR — скажи пользователю ПРЕЖДЕ чем писать код.**
3. Работай только над своим issue. Нет — создай (`gh issue create`), назначь исполнителя, повесь `in-progress`.
4. Ветка: `<владелец>/<номер-issue>-<слаг>` (напр. `oleg/12-fix` / `sava/12-fix` / `codex/12-fix`). Ответвляйся от ветки по умолчанию репозитория.
5. PR сразу как **Draft** (`gh pr create --draft`), в описании — **`Closes #<номер>`**.
6. Лейбл агента: `agent:claude` / `agent:codex`. **В ветку по умолчанию напрямую не пушим.**
7. Доска: https://github.com/orgs/TerrikonTech/projects/1

## 🔴 Общие запреты
- Не коммитим секреты и рантайм-данные: `*token*`, `*secret*`, `*.pem`, `*.key`, БД, живые json-снимки, `node_modules/`, `.venv*/`. Проверяй `.gitignore` перед `git add`, не используй `git add -f` на этих файлах.
- Прод-сервисы трогаем только с явного подтверждения Олега. Репозиторий ≠ автоматический прод: деплой у проектов ручной (SSH-пуш/скрипты), пуш в репо сам по себе на прод не выезжает.
